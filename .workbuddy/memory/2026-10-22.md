## 04:34 默认主窗口导致黑框 + 托盘无菜单（用户截图反馈）
- 用户截图里那个黑框标题是 `E:/PixPin/target/debug/SnapPin.exe`，内容
  「嗯… 无法访问此页面」——**不是悬浮球**，是 Tauri 的默认主窗口。
- 根因：`tauri.conf.json` 没有 `app.windows` 段 → Tauri 自动建主窗口并加载
  `index.html`；本项目是多入口 SPA，`dist/` 下**没有 index.html**
  （只有 ball/pin/menu/main/ocr/trans），所以加载失败 → 黑框 + 报错，
  且干扰 setup 后续逻辑（托盘菜单不弹）。
- 修法：`app.windows = []` 显式禁止自动建窗。提交 0c6442f。
- 教训：多入口项目**必须**在 tauri.conf.json 里关掉默认窗口，否则 debug
  直跑 exe 时必现黑框。之前只有打包版被验证过，没暴露这个坑。

## 04:40 默认主窗口二次修复
- `tauri.conf.json` 的 `app.windows = []` **挡不住** Tauri 自动建主窗口（空数组被当作
  未配置），上一轮 0c6442f 的修法无效，用户截图复现黑框。
- 最终修法（a5d47b7）：`setup` 里起一个后台线程，sleep 300ms 后遍历
  `webview_windows()`，把不在白名单（ball / overlay-* / pin-* / menu / ocr / trans / main）
  里的窗口全关掉，并打日志 `closing unexpected default window: <label>`。
  之所以延后：setup 执行时默认窗口还没被 Tauri 创建。
- 新 exe：target/debug/SnapPin.exe（04:40，48072704 字节）。
- 教训：多入口 SPA 项目，Tauri 默认主窗口必须在运行时清，不能只靠配置。
