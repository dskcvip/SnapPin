## 阶段二：核心能力

- [x] **M3 标注工具（13 种）**（2026-10-21 全部完成，详见 docs/FEATURES.md 三）
  - ✅ 13 种：矩形 / 椭圆 / 箭头 / 铅笔 / 荧光笔 / 马赛克 / 文字 / 序号 / 聚光灯 /
    橡皮擦 / 水印 / 放大镜 / 智能擦除
  - ✅ 贴纸（2026-10-25，emoji + 2079 SVG 图标库 + 中英搜索）、重做（Ctrl+Shift+Z）
  - ✅ 翻译：选区直译已接通（2026-10-25）
  - ⏳ 未做：无（该里程碑已收口）
  - 数据模型可序列化 + Canvas 2D 渲染 + 二次编辑
  - 悬浮球右键菜单（窗口尺寸动画展开）
  - **文字（2026-10-20）**：单击落点开输入框（textarea，中文输入法原生可用），  
    Ctrl+Enter / 失焦提交，Esc 只关输入框不退出截图；前端按 DPR 光栅化成  
    base64 PNG → 核心层 `Shape::Bitmap` + `blit_bitmap` 合成；字号 10~72 可调。  
    设计取舍见 ARCHITECTURE 三·5（字体留 UI 层，保住 core-algo 零依赖）。
  - **序号（2026-10-21）**：单击落点盖编号徽标（圆底 + 数字），与文字共用  
    位图通道（Rust 零改动）；编号取"现有最大号 + 1"，撤销后自动回填不跳号；  
    工具条有独立按钮（圆环内 1），属性面板共用字号滑条。  
    数字按墨迹外接框光学居中（数字字形左右边距不对称，按字宽居中会偏左）。
  - **工具条节距（2026-10-21）**：48px → 40px（图标 22px，间距 26 → 18），  
    分隔线左右留白 8 → 6；17 个按钮总宽 716px（原 16 个按钮为 810px）。
  - **聚光灯（2026-10-21）**：拖拽框选一块区域，区域外按 `dim` 乘性压暗。  
    核心层用圆角矩形 SDF + 1.5px 羽化（`Shape::Spotlight` / `spotlight_region`），  
    只改 RGB 不动 alpha；前端预览走**离屏画布**（整块压暗 → `destination-out`  
    挖洞 → 整张贴回），否则挖洞会把已画好的标注一起擦掉。工具条有独立按钮，  
    属性面板只给一根「暗度」滑条（40~230，默认 150）。
  - **滑条数值（2026-10-21）**：字号/线宽/暗度滑条右侧常显实时数值  
    （`tabular-nums` + 固定最小宽度，拖动时面板宽度不跳）；属性面板抽成  
    `src/annotate/ToolProps.tsx`，可脱离 Tauri 独立挂载做验收。
- [x] **M4 识别能力**（2026-10-21 已接入选区工具条，详见 docs/FEATURES.md 六/七）
  - ✅ OCR：PP-OCRv4 mobile + rten（纯 Rust ONNX），中文场景，结果面板按行可复制
  - ✅ 二维码 / 条码：rxing，支持一图多码、定位点高亮、http(s) 链接可直接打开
  - ✅ 取色器：选区阶段悬停即读数，`C` 复制 HEX（工具条按钮已按要求撤下）
  - 模型按需下载到用户目录，不进安装包
  - ⏳ 未做：表格识别、公式识别、翻译
- [x] **M5 长截图拼接**（2026-10-21 已接入，详见 docs/FEATURES.md 五）
  - ✅ 行哈希 + 偏移匹配 + 累积拼接（core-algo 零依赖 + 单测）
  - ✅ 自动滚动驱动循环、无匹配轻滚重试、到底/静止判定、Esc 停止并出图
  - ✅ 状态条实时缩略图、结果面板三出口（复制/贴图/保存）
  - ✅ 超长模式（自动降采样续拼）+ 独立缩略预览窗（2026-10-25）
