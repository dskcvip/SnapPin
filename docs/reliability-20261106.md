# 可靠性完善及 macOS 核对（2026-11-06）

## 实现

- 配置保存统一通过主窗口 IPC 排队；位置更新只合并位置，设置保存保留最新位置。唯一临时目录在目标卷写入、flush 后直接 rename 替换，不先删除旧配置。保留上一份有效 JSON 备份；损坏 JSON 或字段类型异常时尝试恢复备份，并记录恢复过程。设置已落盘但应用失败时明确提示并允许重试。
- 长图逐行压缩 PNG，避免导出时额外创建整张 RGBA Image 和完整 PNG 副本。文件写入失败保持旧输出。像素尺寸不变，预览仍独立缩小。原图画布仍保留 512MB 安全上限；达到时显式提示并输出已有原图，不降采样。此实现不是磁盘分块的无限画布。
- 长图导出后保留结果元数据；窗口创建或 Dart `pinReady` 确认失败时，预览显示原图路径并允许点击完成重试。重试复用尚存的结果引擎，不重复创建。预览状态消息失败不阻止原图导出。已导出的原图不会因取消错误预览而被删除。
- JPEG 编码和文件写入转到独立 isolate；保存先暂存再替换目标。截图、贴图保存与复制增加处理中状态和失败提示，失败保留截图/编辑内容；处理中阻止重复提交和退出。
- 新建贴图、长图及编辑副本使用带拥有权标记的独立临时目录。关闭结果窗口时显式回收拥有的文件，不依赖 Dart dispose；未交付成功的普通贴图也回收临时文件。只删除明确传入的直属文件，保留额外文件，拒绝目录链接与临时根目录外的路径。OCR 关闭时显式释放独立快照。
- Dart 高频日志改为有界缓冲，100ms 内批量刷盘；失败、就绪、退出及关闭等关键事件立即刷盘，程序退出入口显式 flush。原生日志使用线程锁保护的持久追加句柄，避免每条日志重复创建目录、打开文件。保留详细采集字段；不自动删除已有日志。
- macOS 图片打印改用 NSPrintOperation 系统打印对话框，可选择打印机/取消。CI 只构造真实图片打印任务验证准备路径，不发送打印任务。OCR、翻译、截图撤销提示按 macOS 显示 Command 键标记。
- 启动日志加入提交标识、PID 和系统版本；macOS CI 把 GitHub SHA 编入 Dart，便于区分旧日志。修正文档中把 VMware 12.7.4 写成实体机的环境标记。

## 验证

本地全量 109 项 Flutter 测试通过，包括正文不结束的翻译超时、配置合并/备份恢复/队列错误恢复、流式 PNG 超过 32000px 的宽度和 RGBA 像素检查、导出失败保留旧文件、临时文件拥有权、长图窗口创建失败及延迟就绪的重试、普通贴图创建失败保留选区及回收未交付文件。静态分析无 error/warning，现有及新增风格 info 不阻止构建。

Windows Release 编译、独立配置目录中的原生 OCR/阴影/识别中关闭回归，以及 Intel/arm64 macOS 的源码分析、全量测试、通用包编译、Metal 缺失说明、启动/托盘/退出、原生 OCR、长图焦点/排除/真实滚轮与打印任务准备检查由本轮构建验证。以实际运行日志和包旁 JSON 为最终通过证据，不将尚未结束的构建记录为成功。

## 无法由代码或 CI 消除的边界

- 仓库未配置 Apple 签名及公证凭据，本轮仍为 ad-hoc 签名，不能承诺 Gatekeeper 无拦截或每次升级免授权。正式分发需 Developer ID 和公证凭据。
- CI 系统高于实体 Intel macOS 13.6.6。真实浏览器、触控板、多显示器、TCC 恢复和最终逐像素视觉对照仍需实体机验收。
- 无 Metal 的 VMware 客体仍不能运行 Flutter macOS 界面；现有前置检查只提供明确错误和退出，不补足 GPU 能力。
- 512MB 是原图画布保护，不是 32000px 限制，也不触发图片宽度变化。继续扩大到磁盘分块画布涉及拼接随机访问与结果编辑/导出链路，未在本轮冒险取消内存保护。
- 暂不开发上一张、下一张和收藏；本轮不增加联网 OCR。
