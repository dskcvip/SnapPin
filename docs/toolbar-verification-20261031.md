# 截图工具条验证（2026-10-31）

新增 `test/capture_toolbar_test.dart`，从实际截图选区和工具按钮开始，使用 1400×900 像素测试图。系统插件边界使用测试替身，不需要屏幕录制权限，也不会覆盖用户剪贴板或弹出真实保存对话框。

| 检查 | 验证结果的依据 |
| --- | --- |
| 矩形、椭圆、箭头、画笔、马赛克、聚光灯、序号、贴纸、文字、水印、智能擦除 | 点击工具、在选区操作、完成截图，解码 PNG，核对输出尺寸及实际像素变化 |
| 颜色、线宽、撤销、重做 | 修改颜色和线宽、撤销重做后导出，核对指定颜色与笔画宽度 |
| 橡皮擦 | 快速拖过矩形边缘，核对拖动路径中间恢复原图，未经过的边缘仍保留标注 |
| 二维码 | 生成真实二维码，工具条切换模式并拖选，通过实际识别算法与后台 isolate 解码，在页面显示码内容 |
| 完成并复制 | 核对输出 PNG、恢复悬浮球通知、完成提示窗口创建请求 |
| 保存 | 核对实际写出的 PNG 尺寸；取消保存后仍能继续编辑 |
| 贴图 | 核对实际生成的图片文件、尺寸与查看器窗口创建请求 |
| 本地 OCR、翻译 | 核对送入主窗口识别通道的原尺寸选区 PNG 与结果窗口参数；识别错误时保留选区且不发生布局溢出 |
| 长截图入口 | 核对实际通知主窗口开始长截图、鼠标事件穿透与选区坐标（采集区域扣除四周 4px 边线） |
| 取消 | 核对恢复悬浮球通知与隐藏截图窗口请求 |

本轮发现并修复：

- OCR 错误提示面板固定文本高度加上按钮后超出最大高度，改为文本区在剩余高度内滚动。
- 橡皮擦仅恢复鼠标采样点圆形范围，快速拖动时会留下间隙，改为沿采样点间的路径连续恢复原图。

这些是 Flutter 组件与图像输出集成检查。系统剪贴板、真实文件对话框、macOS Vision 本地 OCR、翻译模型联网及实时滚动采集，仍需要对应平台的权限、服务和真实桌面验证，不能将测试替身通过等同于真机验收。Mac Release 启动、真实子窗口通信和菜单退出另由 `tool/macos_startup_smoke.sh` 在 CI 中检查。
