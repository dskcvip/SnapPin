# 截图效果预览与 Tauri 对齐

- 截图选区中马赛克、聚光灯、橡皮擦和智能擦除显示实际预览，拖动过程中即可看到效果；撤销与重做同步恢复画面。
- 马赛克按原图像素均值绘制；已确认的效果缓存绘制指令，移动光标不重复计算其像素。预览与导出均不降低原图分辨率。
- 橡皮擦预览沿完整路径恢复冻结原图，包含快速拖动时两个采样点之间的部分。
- 智能擦除预览采用 Tauri 的左右边界逐行渐变；原尺寸导出采用 Tauri 的同步波前扩散。新写入像素在下一轮才参与计算，避免方向性条纹，支持边缘与越界区域。
- 聚光灯导出采用 Tauri 的圆角矩形距离场与 1.5px 羽化，修复先前圆角被向外扩张的问题；奇数尺寸按原算法取整。
- 序号读取当前保留标注中的最大编号加一，不再持有会跨截图残留的计数器；撤销后继续添加、重做后分支、新选区及新截图均使用同一规则。
- 日志记录标注提交（工具、点数、序号、参数）、撤销/重做后的下一个序号，以及导出尺寸、工具集合和耗时，不记录输入文字内容。

验证包含实际预览像素、拖动/确认一致性、撤销恢复、快速擦除路径、工具条序号撤销重做后导出，以及 Tauri 原算法生成的 RGBA 参考数据。参考数据来源见 `test/fixtures/README.md`。

这批修改不代表 Intel macOS 13.6.6 的真机权限、多显示器、中文输入法和真实浏览器滚动场景已经验收。
