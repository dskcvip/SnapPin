# 截图结果页、归档与长图接缝

结果页使用 42px 灰色工具栏、细外边框、原生窗口阴影和统一细线图标。九宫格展开/收起 216px 右侧历史栏，三列缩略图按日期分组，可切换日期顺序、刷新、点击打开。悬停 220ms 在缩略图左侧显示预览，移开、滚动或点击时关闭。预览和缩略图解码尺寸受限且保持比例，不修改原图。

通用设置新增截图归档范围，默认仅普通完成截图、贴图（包括剪贴板贴图）、长截图结果，OCR 和翻译截图可自行勾选。旧配置自动采用默认范围，全部取消后保持取消。成功截图归档到安装目录旁的 `截图/yyyy-MM-dd/snappin_YYYYMMDDHHmmss_NNNN.png`，macOS 保存在签名 app bundle 外。另存为是独立副本，取消另存不会生成归档，归档关闭后不删除。命名碰撞重新生成符合既定规则的文件名，使用排他预留和同目录临时文件提交，原始 PNG 字节与分辨率不变。

历史枚举只读取 PNG 头，不全量解码长图；只读取日期目录中的既定文件名。切换时清空标注、缩放、滚动位置，并在有修改时确认保存或放弃。编辑临时图清理只针对本程序创建的临时文件，不删除其他历史原图。

Windows 两轮长图黑屏问题在首帧已出现：即便排除采集接口返回成功，全屏截图输入窗也必须在手动滚动期间隐藏。原生回归用两个自有窗口执行显示、隐藏、区域采集，验证两轮 PNG 均非黑图，不操作用户的 Edge。

重复区块与固定网页提示曾导致短匹配段误判；匹配现在要求足够长的连续支持，并容忍局部遮挡列。Mac 左右两侧重复黑箭头的图形与视口圆角残留相符：向下与向上的接缝改为重叠内容中间，避免把前一帧末端或后一帧起端的窗口边缘反复保留。逐像素回归覆盖左右两侧、向下/向上往返，原宽不裁剪、原像素不降采样。此为对照合成图验证，仍需 Mac 真机核对用户所见伪影。

本地已通过 120 项自动测试及 Windows release 原生 normal/shutdown 回归（含重复采集、窗口阴影、OCR、退出）。新增历史往返切换与编辑测试也通过。设置页和结果页提供离屏渲染检查；当前会话缺少 computer-use 所需 node_repl，未直接点击用户当前 Edge 或 WorkBuddy，不能将离屏/原生回归视为实屏逐像素验收。

归档位置严格遵循安装目录要求，没有悄悄回退到其他目录；安装位置不可写会记录失败并保留选区供重试。macOS 原生窗口外阴影及真实浏览器滚动速度需要实体机验证。
