## 本次已修正

- `lib/translation_service.dart`：原 45 秒超时只覆盖等待响应头，正文流一直不结束时会无限等待。现在整个 HTTP 请求共用 45 秒期限，超时强制关闭连接，并显示明确错误。
- 对缺失、空白和结构异常的翻译响应给出可读错误，避免当作空译文成功或直接暴露类型转换异常。
- 增加翻译开始、成功、超时、失败及耗时日志，不记录原文、译文或 API Key。
- 新增 8 项本地 HTTP 回归，覆盖无响应头、正文中断不结束、正常换行和异常 JSON 结构。全量 99 项测试通过；`flutter analyze --no-fatal-infos` 无 error/warning，48 项 style info；`git diff --check` 通过。

## 验收仍有缺口

- 最近一轮 macOS CI 运行系统高于用户实体 Intel macOS 13.6.6。真实浏览器快速滚轮、拖滚动条跳转后回滚、触控板惯性、不同倍率多屏、权限恢复仍未完成真机验收。
- 设置页、悬浮球、菜单和工具栏的逐像素与完整交互对照仍未完成；组件测试通过不能代替最终桌面视觉验收。
- VMware 日志的 `metalDevices=[]` 来自无 Metal 的虚拟机。不要再将其与能正常普通截图的实体 Intel Mac 混为一谈，也不能承诺应用代码能补足客体 Metal 支持。
- 上一张、下一张与收藏遵照用户要求暂不开发；OCR 富文本复制不属于当前承诺范围。

建议下一轮先完成配置一致性和长图失败恢复，再做大图保存、临时文件回收与日志性能调整，最后用同一提交执行 Windows 发布构建及两架构 macOS CI，打包后下载至 `F:\mac\share`。
